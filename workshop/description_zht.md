[b]客戶端Mod：不會影響遊戲進程。[/b]

[b]瓦庫會關注你做的一切，並對此喋喋不休地低語。[/b]
安裝本Mod並獲得低語耳環後，瓦庫就會不斷插嘴評論你的操作。除了對各種操作作出反應外，他還會指出你的小失誤，嘲笑你的壞運氣，還會為你忘記擁有的遺物而哀嘆。
他會慫恿你在商店大手大腳地花錢，對你獲得的卡牌獎勵說三道四，一旦出現惡魔形態就逼你簽下契約。
總計超過500句台詞。
一項Mod設定還能讓瓦庫從一開始就陪伴你，即使你沒有低語耳環。

[b]分支支援[/b]
同時支援預設分支和公開測試(Public Beta)分支。

[b]前置需求[/b]
BaseLib(作為工作坊相依項目自動安裝)。

[b]支援語言[/b]
作者是日本人，因此除日文外的內容均為AI機器翻譯。歡迎提出修正建議！
我們在Google試算表上徵集並評估各語言版本的台詞，有興趣的話歡迎參與。
